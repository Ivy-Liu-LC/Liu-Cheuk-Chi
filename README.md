# Ivy Liu - Professional Portfolio

This repository hosts my professional portfolio website developed for **IS 3060: Information Systems** at the David Eccles School of Business, University of Utah. It highlights my academic background in biomedical engineering, technical skill set, and upcoming course project deliverables.


## Technologies Used

- **HTML5:** Semantic document structure
- **CSS3:** Responsive layout, flexbox, custom properties (CSS variables), and modern typography
- **Git & GitHub:** Version control and source management
- **GitHub Pages:** Static site hosting and continuous deployment

## Structure

- `index.html` - Primary portfolio homepage containing Header, About Me, Technical Skills, Course Projects, Resume placeholder, and Contact information.
- `README.md` - Project documentation and overview.
